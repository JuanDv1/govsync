# E-02-HU-04 — Cargar la plantilla de proyectos BPIN diligenciada por el municipio

**Como** [[administradora-de-planeacion|Administradora de Planeación]]
**Quiero** cargar la plantilla de proyectos BPIN diligenciada por el municipio
**Para** incorporar la relación entre proyecto, BPIN, indicador y rubro que servirá de puente en el cruce, mientras no exista un archivo estandarizado

## Criterios de Aceptación

### HU04-CA01 — Carga del archivo tal cual

| Campo    | Detalle                                                                                                        |
| -------- | -------------------------------------------------------------------------------------------------------------- |
| Dado     | Un corte existente                                                                                             |
| Cuando   | La administradora carga Proyectos_2026 en el formato en que el municipio lo entrega                            |
| Entonces | El sistema lo almacena asociado al corte, incluso si su estructura interna no está completamente estandarizada |

### HU04-CA02 — Extracción acotada de columnas

| Campo    | Detalle                                                                                                                                            |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | El sistema procesa el archivo                                                                                                                      |
| Cuando   | Extrae la información                                                                                                                              |
| Entonces | Toma específicamente las columnas necesarias para alimentar la matriz de relación (BPIN e indicador de producto), sin validar el resto de columnas |

### HU04-CA03 — Separación de indicadores de producto multivalor

| Campo    | Detalle                                                                                         |
| -------- | ----------------------------------------------------------------------------------------------- |
| Dado     | La columna de indicador contiene varios códigos en una sola celda, separados por salto de línea |
| Cuando   | El sistema procesa el archivo                                                                   |
| Entonces | separarlos automáticamente                                                                      |

### HU04-CA04 — Alimentación de la matriz de relación

| Campo    | Detalle                                                                                 |
| -------- | --------------------------------------------------------------------------------------- |
| Dado     | El archivo fue procesado correctamente                                                  |
| Cuando   | Sus datos alimentan la matriz de relación                                               |
| Entonces | Aporta específicamente las columnas "Cod BPIN" y "Cod Indicador Producto" de esa matriz |
