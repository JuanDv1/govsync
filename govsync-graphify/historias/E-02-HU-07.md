# E-02-HU-07 — Visualizar la matriz de relación del corte actual

**Como** [[administradora-de-planeacion|Administradora de Planeación]]
**Quiero** visualizar la matriz de relación del corte actual
**Para** visualizar al detalle cómo se conectan las tres fuentes sin reconstruir el cruce manualmente

> **Definición del dominio:** Matriz de relación: Tabla con infromación de el código BPIN, el indicador y nombre del producto (SisPT), el indicador de ejecución y el número y descripción del contrato asociado

## Criterios de Aceptación

### HU07-CA01 — Visualización de la matriz de relación

| Campo    | Detalle                                                                                                                                                                           |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | la administradora ha registrado al menos un corte                                                                                                                                 |
| Cuando   | accede a la sección de cortes y selecciona un corte especifico para ver la matriz de relación                                                                                     |
| Entonces | El sistema muestra una matriz, con las seis columnas confirmadas (BPIN, código y nombre del indicador SisPT, código de indicador en ejecución, número y descripción del contrato) |

### HU07-CA04 — Unificación de nombres de columna de indicador

| Campo    | Detalle                                                                           |
| -------- | --------------------------------------------------------------------------------- |
| Dado     | El código de indicador se llama distinto en cada pestaña del archivo presupuestal |
| Cuando   | El sistema construye la matriz                                                    |
| Entonces | Trata ambos nombres como el mismo dato, sin duplicar columnas ni perder filas     |
