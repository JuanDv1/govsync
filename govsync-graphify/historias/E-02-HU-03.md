# E-02-HU-03 — Cargar el archivo presupuestal del corte (con sus pestañas de ejecución y contratación)

**Como** [[administradora-de-planeacion|Administradora de Planeación]]
**Quiero** cargar el archivo presupuestal del corte (con sus pestañas de ejecución y contratación)
**Para** incorporar la información financiera y contractual necesaria para el cruce y la detección de descuadres

## Criterios de Aceptación

### HU03-CA01 — Procesamiento de las dos pestañas

| Campo    | Detalle                                                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Dado     | Un corte existente                                                                                                                                     |
| Cuando   | La administradora carga el archivo presupuestal                                                                                                        |
| Entonces | El sistema reconoce y procesa ambas pestañas (ejecución y contratación) como conjuntos de datos independientes, sin exigir que se carguen por separado |

### HU03-CA02 — Equivalencia de nombres de columna de indicador

| Campo    | Detalle                                                                                                      |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| Dado     | El archivo de ejecución usa CodigoIndicadorCcpet y el de contratación Cod Indicador Ccpet para el mismo dato |
| Cuando   | El sistema procesa ambas pestañas                                                                            |
| Entonces | Reconoce ambos nombres como equivalentes para efectos del cruce posterior                                    |

### HU03-CA03 — Preservación de ceros a la izquierda

| Campo    | Detalle                                                                                                                         |
| -------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | Un archivo de ejecución cargado                                                                                                 |
| Cuando   | El sistema lo procesa                                                                                                           |
| Entonces | Conserva el código de indicador con sus ceros a la izquierda (formato de 9 dígitos), sin convertirlo a un número que los pierda |

### HU03-CA04 — Rechazo por pestaña faltante

| Campo    | Detalle                                                                  |
| -------- | ------------------------------------------------------------------------ |
| Dado     | El archivo cargado no contiene la pestaña "CONTRATACION" o "EJECUCION"   |
| Cuando   | El sistema lo procesa                                                    |
| Entonces | Rechaza la carga y señala específicamente cuál de las dos pestañas falta |

### HU03-CA05 — Rechazo por archivo incorrecto

| Campo    | Detalle                                                                                                                                                    |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | La administradora carga un archivo que no corresponde al archivo de ejecución (por ejemplo, sube por error el PDT o el archivo del municipio en este paso) |
| Cuando   | El sistema lo procesa                                                                                                                                      |
| Entonces | Rechaza la carga indicando que el archivo no corresponde al formato esperado, sin intentar adivinar su contenido                                           |

### HU03-CA06 — Alimentación de la matriz de relación (ejecución)

| Campo    | Detalle                                                                                                                                                   |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | El archivo de ejecución fue procesado correctamente                                                                                                       |
| Cuando   | Sus datos alimentan la matriz de relación                                                                                                                 |
| Entonces | Aporta específicamente la columna "Cod Indicador" (pestaña ejecución) y las columnas "Núm. Contrato" y "Descripción" (pestaña contratación) de esa matriz |
