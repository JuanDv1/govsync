# E-02-HU-01 — Crear un corte indicando vigencia y fecha exacta

**Como** [[administradora-de-planeacion|Administradora de Planeación]]
**Quiero** crear un corte indicando vigencia y fecha exacta
**Para** agrupar bajo una misma referencia las fuentes y resultados de un momento de seguimiento

**Lleva a:** [[E-02-HU-02]], [[E-02-HU-03]], [[E-02-HU-04]]

## Criterios de Aceptación

### HU01-CA01 — Ingreso de Vigencia del corte

| Campo    | Detalle                                                                                                                    |
| -------- | -------------------------------------------------------------------------------------------------------------------------- |
| Dado     | La administradora ha iniciado sesión, se encuentra en el módulo Cortes y selecciona "Nuevo Corte"                          |
| Cuando   | ingresa vigencia seleccionando la fecha en el calendario                                                                   |
| Entonces | El sistema la acepta y avanza al paso de carga de archivos fuente:<br>[[E-02-HU-02]] <br>[[E-02-HU-03]] <br>[[E-02-HU-04]] |

### HU01-CA02 — Vigencia con fecha futura

| Campo    | Detalle                                                                                                                |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| Dado     | La administradora ha iniciado sesión, se encuentra en el módulo Cortes y selecciona "Nuevo Corte"                      |
| Cuando   | ingresa vigencia seleccionando la fecha futura en el calendario                                                        |
| Entonces | El sistema no permite el ingreso de la vigencia y muestra un mensaje indicando que no se pueden agregar cortes futuros |

### HU01-CA03 — Corte no se registra sin archivos completos

| Campo    | Detalle                                                                                   |
| -------- | ----------------------------------------------------------------------------------------- |
| Dado     | Falta alguno de los archivos obligatorios (considerando los reutilizados automáticamente) |
| Cuando   | La administradora da clic en "Guardar"                                                    |
| Entonces | El sistema rechaza la operación, indica qué archivo falta, y no registra el corte         |

### HU01-CA04 — Registro exitoso del corte

| Campo    | Detalle                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------ |
| Dado     | La vigencia es válida y los tres archivos obligatorios están disponibles (nuevos o reutilizados) |
| Cuando   | La administradora da clic en "Guardar"                                                           |
| Entonces | El sistema registra el corte y lo agrega al historico de cortes de seguimiento                   |

### HU01-CA05 — Reutilizacion automatica del PDT y archivo de municipio

| Campo    | Detalle                                                                                                                     |
| -------- | --------------------------------------------------------------------------------------------------------------------------- |
| Dado     | La administradora ya creó al menos un corte anterior con PDT y archivo del municipio cargados                               |
| Cuando   | Inicia el proceso de un nuevo corte                                                                                         |
| Entonces | El sistema muestra el PDT y el archivo del municipio ya registrados de la carga anterior, sin exigir que se vuelvan a subir |

### HU01-CA06 — Opción de reemplazar archivos reutilizados

| Campo    | Detalle                                                                              |
| -------- | ------------------------------------------------------------------------------------ |
| Dado     | El sistema está reutilizando el PDT o el archivo del municipio de una carga anterior |
| Cuando   | La administradora quiere actualizarlos                                               |
| Entonces | Tiene la opción de reemplazarlos por una versión nueva en ese mismo paso             |

### HU01-CA07 — Archivo de ejecución siempre solicitado

| Campo    | Detalle                                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------------------- |
| Dado     | Cualquier corte, primero o posterior                                                                                      |
| Cuando   | La administradora llega al paso de carga de archivos                                                                      |
| Entonces | El sistema siempre solicita el archivo de ejecución correspondiente a ese corte, nunca se reutiliza de una carga anterior |
