# E-02-HU-02 — Cargar el archivo fuente: Plan indicativo

**Como** [[administradora-de-planeacion|Administradora de Planeación]]
**Quiero** cargar el archivo fuente: Plan indicativo
**Para** incorporar las metas, programación, estructura, información financiera e información presupuestal del plan que serán usadas en el seguimiento

## Criterios de Aceptación

### HU02-CA01 — Reconocimiento de la pestaña de metas del PDT

| Campo    | Detalle                                                                                                                                                                                   |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | Un corte está en proceso de creación o ya creado                                                                                                                                          |
| Cuando   | La administradora carga un archivo de PDT (Plan Indicativo) válido                                                                                                                        |
| Entonces | El sistema reconoce específicamente la pestaña "Plan indicativo - Productos" (entre las varias que trae el archivo real) y no intenta interpretar las demás pestañas como si fueran metas |

### HU02-CA02 — Rechazo por columnas faltantes

| Campo    | Detalle                                                                                                                                             |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | Un archivo de Plan Indicativo que no contiene las columnas mínimas esperadas (código de indicador, meta programada por vigencia, marca "Principal") |
| Cuando   | El sistema lo procesa                                                                                                                               |
| Entonces | Rechaza la carga completa del archivo y señala qué columna(s) faltan, sin incorporar datos parciales                                                |

### HU02-CA03 — Confirmación visual de metas cargadas

| Campo    | Detalle                                                                      |
| -------- | ---------------------------------------------------------------------------- |
| Dado     | El archivo se cargó correctamente                                            |
| Cuando   | La administradora consulta el corte                                          |
| Entonces | El sistema confirma visualmente cuántas metas fueron reconocidas del archivo |

### HU02-CA04 — Rechazo por archivo incorrecto

| Campo    | Detalle                                                                                                                           |
| -------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Dado     | La administradora carga un archivo que no corresponde a un PDT (por ejemplo, sube por error el archivo de ejecución en este paso) |
| Cuando   | El sistema lo procesa                                                                                                             |
| Entonces | Rechaza la carga indicando que el archivo no corresponde al formato esperado de PDT, sin intentar adivinar su contenido           |

### HU02-CA05 — Alimentación de la matriz de relación (PDT)

| Campo    | Detalle                                                                                            |
| -------- | -------------------------------------------------------------------------------------------------- |
| Dado     | El archivo de PDT fue procesado correctamente                                                      |
| Cuando   | Sus datos alimentan la matriz de relación                                                          |
| Entonces | Aporta específicamente las columnas "Cod Indicador Producto" y "Nombre del producto" de esa matriz |
